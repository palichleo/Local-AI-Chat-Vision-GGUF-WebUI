Atelier native workflows: your own

This folder holds YOUR native workflows, one JSON file per workflow, named by its stable id
followed by .json: the ones you create, import, and your edited versions of the workflows
shipped with Atelier. Edit or import them through Settings > Workflows so policies and local
assets are validated before saving.

The workflows shipped with Atelier live in runner/workflows/ and come with every download and
update. Updates never touch this folder: a workflow you edited or created is never replaced.
When an update brings a new version of a workflow you edited, or a workflow named like one of
yours, the new one is listed beside yours as "... V2" (then V3...). A shipped workflow you
delete stays hidden until an update changes it; "Réafficher" in Settings shows it again.

Fixed values are locked. Model values allow the assistant to choose only within your
configured choices/ranges. Random is only for seeds. LoRA off never loads the adapter.
Reference inputs have named roles and accept only staged chat/library resources.

Do not place ComfyUI editor/API graphs, model weights, caches or outputs here. Original
generation media belongs in output/ and is preserved when chat history is deleted.
These files are user data and are excluded from version control.
