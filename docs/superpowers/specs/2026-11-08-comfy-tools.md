# Local ComfyUI tools: agreed behavior

- Existing HTML/CSS/JS app and Node22 backend remain local on Windows/Linux; no new npm dependencies, model downloads, cloud service or changes to original workflows.
- The model receives real OpenAI-style tools describing imported ComfyUI workflows. Ordinary chat does not execute workflows. Native calls have been verified on the actual Q6_K model.
- Registered API workflow graphs are copied under ignored data/workflows. Only explicitly mapped prompt/negative/seed/dimensions/image fields may change; the model cannot rewrite arbitrary workflow nodes.
- Default permission asks before execution. The user can allow one execution or globally allow imported workflows, with a revocable setting. Default maximum three generations per user turn, configurable 1–10,000 (∞ in the UI).
- Execution alternates VRAM: wait for idle Comfy, stop llama-server and projector, run one approved graph, capture final saved image descriptors, unload Comfy models and verify release, restart llama-server for vision review. Existing Comfy server remains running. Cancellation/errors restore a usable model state when possible and never interrupt an unrelated queued job.
- The model reviews output against the original instruction and selected references, can revise within the iteration limit, and reports uncertainty. The app does not claim that evaluation is infallible or retrain weights.
- Right gallery shows original workflow output with original viewing/download, prompt, workflow, seed and status. Original files remain managed by ComfyUI outside project history. Only compressed analysis images and links/metadata follow the conversation-history setting and are deleted by clear history.
- Browser prepares analysis copies, keeping the smaller PNG/JPEG result, max side1024 and a shared four-megapixel budget. Up to64 references per message; total HTTP body remains20MiB. Explain effective analysis resolution and context limits; do not promise64 full-resolution images fit every model/context.
- Pending approvals/jobs are explicit, with cancel/progress and no silent execution after page restoration. History can restore native tool transcript and gallery metadata without rerunning a workflow.
- Test mock protocols, permissions, VRAM sequencing/recovery, history deletion preserving originals, original byte fidelity, and actual model calls. Test an existing real Comfy workflow if possible. Stop every app/model instance launched for testing when finished; do not stop the user's existing Comfy server.

Settings UX: native Windows/Linux file pickers, bounded local Comfy discovery (saved address,8188,7821), detected read-only address with manual override, one shared Save that closes the centered settings dialog, current-address connection testing, multi-file API imports and editable descriptions advertised to native workflow selection.
